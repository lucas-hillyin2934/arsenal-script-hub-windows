## What It Does

Arsenal Script Hub is a standalone Windows executable for keeping Roblox Arsenal preferences organized. From the application, users can save and restore loadout presets, modify the appearance of the crosshair, choose HUD arrangements, and maintain separate sensitivity setups.

In addition to preference management, the utility keeps match statistics on the local machine, exports configuration data, and offers a way to restore default settings. It can detect when Arsenal starts and includes an updater for refreshing the installed build when newer releases are available.
